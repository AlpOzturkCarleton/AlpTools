Folder Structure Generator Tool

Design a folder structure once, then generate a ready-to-run Terminal or PowerShell command that builds it anywhere.

Windows (PowerShell)

  • Start Menu Search: Press the Windows key, type "powershell", and press Enter.

macOS (Terminal)

  • Spotlight Search: Press Command + Spacebar, type "terminal", and press Enter.

Ubuntu (Terminal)

  • Keyboard Shortcut: Press Ctrl + Alt + T to instantly open a new terminal window.

Don't know how to get your file path?

Windows 11

  • Open Windows File Explorer and select your folder.
  • Click the three dots (...) at the top menu and select Copy path.
  • Keyboard shortcut: Select the item and press Ctrl + Shift + C.
  • Alternatively, click the address bar at the top (Alt + D) to highlight and copy the text path.

macOS

  • Open Finder and select the folder.
  • Keyboard shortcut: Press Option + Command + C to copy the full path directly.
  • Menu option: Go to View > Show Path Bar to see the full hierarchy at the bottom of the window, then right-click a folder name and choose Copy Pathname.
  • Press and hold the Option key while right-clicking a folder in Finder to reveal the Copy as Pathname option.

Ubuntu (Linux)

  • Open the Files app (Nautilus) and go to the target folder.
  • Keyboard shortcut: Press Ctrl + L to change the breadcrumb bar into an editable text path.
  • Copy the highlighted text directly from that address bar.
  • Terminal check: Open terminal inside a folder or use the pwd (print working directory) command.
