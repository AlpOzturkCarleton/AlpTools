# AlpTools
Various tools for Alp in conducting Data Services. All of which are HTML pages where data is formatted for use.

## Folder Structure Generator 
To be used to create a folder structure at once using powershell or terminal. 

## Libinsight Records Builder
Build your full LibInsight records and export it to CSV for uploa, inlcudes expanded internal notes builder.

## Data Service Internal Notes Builder
Build your internal notes for assessment. (Legacy version of the Records Builder)

## ReadMe Generator
  This tool is based on the McMaster University
  README Generator (rdm.mcmaster.ca/readme), developed by Richie Motorgeanu,
  Debbie Lawlor, Rebeca Gaston Jothyraj, Danica Evering, and Isaac Pratt
  (McMaster University Research Data Management), made available under a
  Creative Commons Attribution 4.0 International (CC BY 4.0) licence. The
  original tool was in turn inspired by the Cornell University "Guide to
  writing readme-style metadata" and the Citation File Format initializer
  (cffinit, citation-file-format.github.io/cffinit). This adaptation, and any
  modifications made to it, are shared under the same CC BY 4.0 licence.

  This file is fully self-contained: no external stylesheets, fonts,
  scripts, or network requests are required. Save/download this single
  .html file and open it in any modern browser to run the generator
  completely offline. Nothing you type is sent anywhere — it stays in your
  browser's memory until you close the tab, unless you use "Save draft"
  to download it to your own computer.
